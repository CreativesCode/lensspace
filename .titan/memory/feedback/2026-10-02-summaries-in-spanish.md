Date: 2026-10-02

The product owner asked that every summary and status report addressed to them
(end-of-task summaries, "qué falta", explanations of steps they must do) is written
in Spanish. Code, identifiers, commits, migrations, plans and memory entries stay in
English as the project rules require. Applies to both agents (Claude Code and Codex).
