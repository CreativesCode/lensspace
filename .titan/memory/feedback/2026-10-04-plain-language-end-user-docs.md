# End-user documentation in plain Cuban Spanish

Date: 2026-10-04

## Rule

The product owner wants every end-user document (the in-app manual at `/manual`, its
PDF, help text written for optician staff or owners) to be understandable by people
with little technology experience in Cuba.

- Address the reader as «tú»; short sentences; one action per step.
- Use local everyday words: «espejuelos», «la tasa del día» (CUP per 1 USD), «lo que
  falta por pagar», «el móvil/teléfono». Avoid jargon such as «transición»,
  «atómica», «inmutable», «flujo», «módulo», «rol».
- Quote button labels exactly as the UI shows them, in «comillas».
- Explain the why in one line when a rule blocks the user (e.g. no delivery with
  balance due).
- Illustrate with real screenshots, taken only from test organizations (names starting
  with «QA»); never from Óptica Javier, the real pilot organization.

## Why

The owner judged the earlier technical manual too hard for the ópticas' staff and
owners, and adopted the 2026-10-04 plain-language rewrite as the official site
documentation.
