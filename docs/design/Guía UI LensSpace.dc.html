LensSpace Guía UI 2.0 · propuesta

Auditoría visual y un solo archivo con las piezas para rediseñar todas las vistas.

La landing ya tiene carácter; la app no. Esta guía lleva la energía de la landing a los componentes compartidos, así cada vista mejora al cambiar las piezas — no hay que rediseñarlas una por una.
